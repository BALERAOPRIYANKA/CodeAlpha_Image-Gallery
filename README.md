Project Overview

This project is a responsive Image Gallery developed using HTML, CSS, and JavaScript. It allows users to browse images, filter them by category, and view them in a lightbox with navigation controls.

Objectives

- Design an interactive image gallery.
- Implement category-based image filtering.
- Provide a lightbox view for enhanced image viewing.
- Create a responsive layout for different screen sizes.
- Improve user experience with smooth animations and transitions.

Features

- Responsive image gallery layout.
- Image filtering by categories.
- Lightbox image viewer.
- Previous and Next image navigation.
- Hover effects and smooth transitions.
- Mobile-friendly design.

Technologies Used

- HTML5
- CSS3
- JavaScript

Project Structure

- HTML for page structure.
- CSS for styling and responsiveness.
- JavaScript for filtering, lightbox functionality, and image navigation.

How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run the "index.html" file in a web browser.

- Enhanced front-end development skills.
